## 📖 About the Project

This project analyzes **9,551 Zomato restaurants** across multiple countries and presents the findings in an interactive **Google Sheets dashboard**. It covers restaurant distribution, cuisines, ratings, votes, pricing and service availability.

### ❓ Questions Answered

| # | Question |
|:-:|---|
| 1 | Which countries have the most restaurants on Zomato? |
| 2 | How has the number of restaurants changed over the years? |
| 3 | Which cuisines are the most popular? |
| 4 | How do ratings and votes vary by country? |
| 5 | How many restaurants offer online delivery and table booking? |
| 6 | What is the average cost for two (in INR)? |

## 🔍 Key Insights

- 🇮🇳 **India** has by far the highest number of restaurants in the dataset.
- 📈 Restaurant count stays fairly steady across the years shown.
- 🍛 **North Indian** is the most common cuisine, followed by Chinese and Fast Food.
- 🛵 Most restaurants do **not** offer online delivery.
- ⭐ Average ratings are similar across countries (around **2.8 – 2.9**).
